# Security

Since this repository is not software, but just build instructions, there
is no need to report security issues here. Instead, report them to the
appropriate other project (Docker's distroless containers, stunnel's
static-curl, Atuin itself) and once they have created a new release that
fixes the security issue, if Dependabot has not created a pull-request
to do the update (iirc, it checks weekly), raise an issue here.

You may also wish to read [docs/transparency.md](docs/transparency.md).
